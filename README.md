# portfolio

Personal site of Aswin Krishnamoorthy — https://aswin-krishnamoorthy.vercel.app

Next.js 16 · React 19 · Tailwind CSS 4 · TypeScript · Node 24. The app lives in `my-portfolio/`.

```bash
cd my-portfolio
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

All content (roles, case studies, stack) comes from `my-portfolio/data/index.ts`.
The résumé PDF is served from `my-portfolio/public/pdf/AswinResume.pdf`.
